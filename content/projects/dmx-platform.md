DMX Platform
============

➜ Platform for knowledge building, data modeling, and collaboration.  
➜ **Semantic desktop** featuring *Bring-to-me navigation* for preserving stable visual contexts.  
➜ Application server and full-stack web development framework.

For 8 years (2017-2025) the DMX Platform was powering the [DMX Systems UG](https://www.linkedin.com/company/dmx-systems/) (now defunct).
Its [Linqa](/project/linqa) product is built on top of the DMX platform.

DMX Platform is the 5th iteration of the 25+ years running Open Source project "DeepaMehta".
Starting with version 5 "DeepaMehta" was renamed to "DMX".
At the moment the DMX platform is not actively developed.
The final version is DMX 5.3.5.
Its successor project is [DM6 Elm](/project/dm6-elm).

Documentation
-------------

DMX documentation is available online at Read the Docs. There is a user guide, a developer guide, and an administrator guide.
Also some DMX plugins are covered, like `dmx-geomaps`, `dmx-tableview`, `dmx-file-upload`, `dmx-sendmail`, and `dmx-ldap`.

[https://dmx.readthedocs.io](https://dmx.readthedocs.io)

An alternative DMX user guide is available as PDF. It is written by community member Liangbing Zhu as part of his doctoral research and features a knowledge sharing use case about Chinese traditional ballads.
